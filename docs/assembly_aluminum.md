# 알루미늄 조립: 앵글 가공표 · 리벳 지도 · 히터 덕트 (v3.4.0, 알루미늄 전부 1T)

업체 가공 부품은 Release `_vendor_aluminum.zip` 한 묶음 (v3.4.0: 알루미늄 전부 1T, 히터 덕트·E07 포함). 업체에 올리는 파일은 발주표 "올릴 파일" 열: 평판 = `dxf/` + `step/`, 절곡 = `step/` + `2D도면.pdf`. 이 문서는 **직접 하는 일**만 적는다.
치수의 원본은 `cad/herb_dryer_cad.py`. CAD가 바뀌면 이 표도 다시 확인한다.

## 1. 앵글 10×10×1 가공표 (직접 자르는 경우)

L자 9종 16개는 **업체 1T 절곡** (`params.yaml` `VENDOR.l_angles: true`, 팀 11/23) → 이 표는 업체가 L자를 빼거나 못 접을 때만 쓴다 (그때는 `VENDOR.l_angles: false`로 묶음에서 빼고 BOM 60번 앵글 10×10×1 1m ×4).

| 부품 | 길이 × 수량 | 구멍 | 붙이는 법 |

- A14·A19 L·R은 좌우 대칭 (한쪽은 뒤집은 모양)
- 도구: 쇠톱, 직각자(또는 마이터 박스), 쇠줄, 센터펀치

## 2. 리벳 지도

CAD에는 리벳 구멍이 없다 (일부러). 조립 때 두 판을 겹쳐 Ø3.3으로 같이 뚫는다. 리벳 Ø3.2×6 알루미늄.

| 이음 | 개수 [가정] | 메모 |
|---|---|---|
| T03 모서리 판 ↔ 긴 변·짧은 변 바닥 다리 | 4곳 × 2 = 8 | 모서리 판 20×20을 바닥 다리 밑에 |
| 십자 띠 끝 ↔ 바닥 다리 | 4 | |
| 십자 띠 교차점 | 1 | 한 띠가 위 |
| T04 ↔ 십자 띠 | 4 | 핀 구멍 Ø5.6 피해서 |
| 메시 ↔ 바닥 다리·십자 띠 (위에 와셔) | 약 20 | 둘레 약 50mm 간격 + 띠 위 몇 곳. 와셔 → 메시 → 다리(띠) 순서로 관통 |
| A16 ↔ A19 L·R | 3 × 2 = 6 | 139 길이에 균등 |
| A16 ↔ A20 | 5 | 246 길이에 균등 |
| A18 ↔ A15 | 2 | 또는 중성 실리콘 |
| 히터 덕트 (2차): 끝판 H11·창판 H09 날개 ↔ 몸통 H06 옆벽 | 2 × 2 × 2 = 8 | 날개마다 2개 |
| 히터 덕트 (2차): 뚜껑 H10 날개 ↔ 몸통 H06 옆벽 | 3 × 2 = 6 | |
| 합계 | 약 64 | 100개(50 ×2) 구매로 충분 |

- 물림 두께: 와셔 + 메시 0.6 + 1T 다리 ≈ 2.5, 띠 2장 + T04 = 3 → Ø3.2×6 범위 안 (봉지의 물림 표기 확인)

## 3. 트레이 조립 순서 (v3.2.0)

1. 앵글 긴 변 2 + 짧은 변 2를 맞대고, 모서리 판 20×20 ×4를 바닥 다리 밑에 리벳
2. 십자 띠 X(243, 핀 구멍 Ø5.6 ×2)·Y(242)를 바닥 다리 위에 리벳, 교차점 1개
3. T04 가운데 판을 띠 위에 리벳 (핀 구멍끼리 맞춤)
4. 메시 243×241.5를 바닥 다리·띠·T04 위에 얹고, 받침 핀 자리에 Ø6 구멍 2개 → 위에서 와셔 + 리벳
5. 세운 다리가 메시 위로 약 7.4mm 남아 트레이 테두리가 된다

실제로 겹치는 높이 (CAD는 단순화해서 모두 같은 높이로 그림):
- 바닥 다리 위에 띠 X·Y(1T)가 얹히고, 교차점에서 한 띠가 위로, 그 위에 T04(1T) → 가운데가 둘레보다 약 3mm 높다. 메시는 가운데가 살짝 솟은 채로 리벳하면 된다 (잎에는 문제 없음)
- 트레이는 띠 X·T04가 로드셀 받침판 L04 위에 얹혀 지지된다 → 프레임 둘레는 CAD보다 약 1mm 낮게 앉는다. 옆 틈막이 A14와의 간격은 가로 2mm라 영향 없음

## 4. 그 밖에

- A11 차폐판 + L04 받침판: 트레이 블록 윗면에 **중성 실리콘**으로 접착 (PVC 본드·순간접착제 금지)
- 라이너 케이블 구멍 Ø16 ×4 (A02_R ×2, A04_R ×2)와 칸막이 A15 Ø16 (v3.5.0): **실리콘 그로밋** (BOM 51번, 장착 구멍 Ø16·판 1mm·안지름 12 이상)
- A02_R의 전력선 구멍은 PG9 글랜드 축보다 4mm 뒤에 있다 (앞 모서리 여유). 폼 구멍 Ø28 안이라 선은 그대로 지나간다
- 라이너 이음매: 알루미늄 테이프 (히터 덕트 주변은 꼭 — 폼 XPS 한계 약 70°C)

## 5. 히터 덕트 조립 (v3.3.0, v3.7.0 끼움 여유 0.5)

부품: H06 몸통(1T ㄷ자) · H10 뚜껑(1T) · H11 끝판(1T, 팬 쪽, Ø56) · H09 PTC 창판(1T) · H03 PTC · H05 95°C 서모스탯 · H12 세라믹 단자대

1. PTC를 창판 H09 개구에 맞춰 대고 장착 구멍 4개를 표시 → Ø3.4로 직접 뚫기 (업체 도면엔 구멍 없음, v3.3.1).
   PTC를 M3×30 4개로 단다 (볼트 머리 = 출구 쪽, 너트 = 팬 쪽). 개구가 핀 면보다 크면 남는 곳을 알루미늄 테이프로, 작으면 줄로 넓힘
2. 끝판 H11·창판 H09를 몸통 H06 안에 넣고 날개를 옆벽에 겹쳐 리벳 (날개마다 2개). 판 둘레 틈은 알루미늄 테이프
   - v3.7.0 끼움 여유: H09·H11 판 폭 106.5 ↔ H06 안쪽 107 (한쪽 0.25). H09·H11 아래 두 모서리가 H06 안쪽 둥근 모서리(R 약 1)에 걸리면 줄로 C1 정도 갈아냄
3. 몸통 오른벽에 95°C 서모스탯: 캡이 PTC 오른쪽 끝면에 닿게, 브래킷과 벽 사이 M3 와셔로 높이 맞춤 (약 2.4)
4. PTC 리드선은 출구(앞) 쪽으로 빼서 H12 세라믹 단자대에서 실리콘 18AWG로 연장 → PG9 전력 글랜드
5. 덕트 바닥 Ø3.4 ×2 → M3 와셔 3장 → 스탠드오프 (M3×8). 끝판은 팬 볼트 M3×30 4개로 칸막이·팬과 같이 조임
6. 뚜껑 H10을 씌우고 날개를 옆벽 바깥에 리벳 3개씩. 이음매 알루미늄 테이프 (뚜껑 안쪽 109.5 ↔ H06 바깥 109, v3.7.0)

- 2차 묶음은 1차와 같이 발주해도 된다 (v3.3.1). 창판 개구 56×28은 PTC 핀 면 [가정], 장착 구멍은 PTC 실물에 맞춰 직접 → 실측값은 나중에 `params.yaml` PTC에 반영 (기록용)
- 몸통·뚜껑·끝판은 PTC 크기와 무관 (창판만 PTC에 맞춤)
- 업체 도면의 ㄷ자 부품(H06·H09·H10·H11·A12·E07)은 "보이는 면 = 바깥, 날개·옆벽은 도면 뒤쪽으로". H06은 구멍이 한쪽에 치우쳐 반드시 이 방향
