# 알루미늄 조립: 앵글 가공표 · 리벳 지도 (v3.2.0)

업체 가공 부품은 Release `_vendor_aluminum.zip`(발주표·확인도면). 이 문서는 **직접 하는 일**만 적는다.
치수의 원본은 `cad/herb_dryer_cad.py`. CAD가 바뀌면 이 표도 다시 확인한다.

## 1. 앵글 10×10×1 가공표 (직접 자르는 경우)

알루미늄 묶음의 "1T 절곡 (앵글 대신)" 13개를 업체에 맡기면 이 표는 필요 없다 (BOM 60번 앵글도 사지 않음).
구매 1m ×4 (1개 여분). 구멍 Ø3.4, "벽 다리" = 벽에 붙는 다리, 구멍은 다리 폭 가운데(모서리에서 5).

| 부품 | 길이 × 수량 | 구멍 | 붙이는 법 |
|---|---|---|---|
| A17_floor_angle_F | 269 ×1 | 없음 | 라이너에 중성 실리콘 |
| A17_floor_angle_L·R | 214.5 ×2 | 없음 | 중성 실리콘 |
| A17_floor_angle_LB·RB | 12.5 ×2 | 없음 | 중성 실리콘 |
| A20_duct_floor_angle | 247 ×1 | 없음 (리벳은 겹쳐 뚫기) | A16 아래 앞면에 리벳 |
| T03 긴 변 | 245 ×2 | 없음 (리벳) | 모서리 판·십자 띠·메시 리벳 |
| T03 짧은 변 | 224 ×2 | 없음 (리벳) | 긴 변 사이 맞대기 |
| A14_tray_gap_strip_L·R | 229 ×2 | 벽 다리에 2개: 앞 끝에서 47.5, 177.5 | M3 볼트로 옆벽 관통 |
| A19_duct_wall_angle_L·R | 139 ×2 | 벽 다리에 2개: 아래 끝에서 39, 109 | M3 볼트로 옆벽 관통 + A16 리벳 |
| A18_partition_angle | 20 ×2 | 바닥 다리 가운데 1개 (끝에서 10) | 스탠드오프에 볼트 + A15에 리벳 또는 실리콘 |

- 1m 막대 나누기: ① 269 + 247 + 245 + 229 ② 245 + 224 + 224 + 229 ③ 214.5 ×2 + 139 ×2 + 20 ×2 + 12.5 ×2
- A14·A19 구멍은 포맥스 옆판 구멍에 대고 따라 뚫는 게 더 정확하다
- A14·A19 L·R은 좌우 대칭 (한쪽은 뒤집은 모양)
- 도구: 쇠톱, 직각자(또는 마이터 박스), 쇠줄, 센터펀치

## 2. 리벳 지도

CAD에는 리벳 구멍이 없다 (일부러). 조립 때 두 판을 겹쳐 Ø3.3으로 같이 뚫는다. 리벳 Ø3.2×6 알루미늄.

| 이음 | 개수 [가정] | 메모 |
|---|---|---|
| T03 모서리 판 ↔ 긴 변·짧은 변 바닥 다리 | 4곳 × 2 = 8 | 모서리 판 20×20을 바닥 다리 밑에 |
| 십자 띠 끝 ↔ 바닥 다리 | 4 | |
| 십자 띠 교차점 | 1 | 한 띠가 위 |
| T04 ↔ 십자 띠 | 4 | 핀 구멍 Ø5.6 피해서 |
| 메시 ↔ 바닥 다리·십자 띠 (위에 와셔) | 약 20 | 둘레 약 50mm 간격 + 띠 위 몇 곳. 와셔 → 메시 → 다리(띠) 순서로 관통 |
| A16 ↔ A19 L·R | 3 × 2 = 6 | 139 길이에 균등 |
| A16 ↔ A20 | 5 | 247 길이에 균등 |
| A18 ↔ A15 | 2 | 또는 중성 실리콘 |
| H08 ↔ H06 (2차) | 2 × 2 = 4 | |
| 합계 | 약 54 | 100개(50 ×2) 구매로 충분 |

- 물림 두께: 와셔 + 메시 0.6 + 1T 다리 ≈ 2.5, 띠 2장 + T04 = 3 → Ø3.2×6 범위 안 (봉지의 물림 표기 확인)

## 3. 트레이 조립 순서 (v3.2.0)

1. 앵글 긴 변 2 + 짧은 변 2를 맞대고, 모서리 판 20×20 ×4를 바닥 다리 밑에 리벳
2. 십자 띠 X(243, 핀 구멍 Ø5.6 ×2)·Y(242)를 바닥 다리 위에 리벳, 교차점 1개
3. T04 가운데 판을 띠 위에 리벳 (핀 구멍끼리 맞춤)
4. 메시 243×242를 바닥 다리·띠·T04 위에 얹고, 받침 핀 자리에 Ø6 구멍 2개 → 위에서 와셔 + 리벳
5. 세운 다리가 메시 위로 약 7.4mm 남아 트레이 테두리가 된다

## 4. 그 밖에

- A11 차폐판 + L04 받침판: 트레이 블록 윗면에 **중성 실리콘**으로 접착 (PVC 본드·순간접착제 금지)
- 라이너 케이블 구멍 Ø12 ×4 (A02_R ×2, A04_R ×2)와 칸막이 A15 Ø12: **실리콘 그로밋** (BOM 51번)
- 라이너 이음매: 알루미늄 테이프 (히터 덕트 주변은 꼭 — 폼 XPS 한계 약 70°C)
