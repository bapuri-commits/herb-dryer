# 부품 실측 기록

부품이 도착하면 재서 여기에 남기고, `실측 결과` 이슈를 연다. 통합 담당이 `cad/params.yaml`에 반영한다 (패치 버전).

## 파일 이름

```
docs/measurements/<params.yaml 그룹>_<날짜>_<측정자>.md
docs/measurements/<params.yaml 그룹>_<날짜>_<측정자>_1.jpg
```

예: `PTC_2026-11-14_hong.md`, `PTC_2026-11-14_hong_1.jpg`

사진은 긴 변 1600px 이하로 줄여서 올린다 (레포가 무거워짐). 버니어캘리퍼스 눈금이 보이게.

## 기록 양식 (복사해서 쓰기)

```markdown
# PTC 발열체 실측

- 부품: PTC 발열체 12V 80W (BOM No 8)
- 측정자·날짜: 홍길동 2026-11-14
- 도구: 디지털 버니어캘리퍼스 (0.01mm)
- 이슈: #12

| params.yaml 키 | 지금 값 | 잰 값 | 비고 |
|---|---|---|---|
| PTC.w | 70 | 71.8 | 핀 끝까지 |
| PTC.d | 26 | 25.4 | |
| PTC.h | 35 | 35.2 | 전선 제외 |

![정면](PTC_2026-11-14_hong_1.jpg)
```

## 규칙

- 같은 곳을 **3번 재서 평균** (소수 첫째 자리)
- 판매처 표기와 다르면 둘 다 적는다
- 구멍은 중심 간 거리로 (구멍 바깥끼리 잰 값 − 구멍 지름)
